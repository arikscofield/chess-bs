# Bluff/BS Chess

Current WIP

run `npm install` in `/common/`, `/server/`, and `/client/`

Requires PostgreSQL server. Replace /server/.env.example with database url.
Then run `npx drizzle-kit push` in `/server` to instantiate the database schema.

run `npm run build` in `/common`

run `npm run dev` in both `/server` and `/client`
